# VetConnect

Plataforma de telemedicina veterinaria — Grupo Pinnacle 2025

## Estructura del proyecto

- `/backend` — Servidor Node.js con TypeScript y Express
- `/mobile` — App Android con React Native y Expo
- `/web` — Interfaz web con React y Vite

## Stack tecnológico

Node.js, TypeScript, Express, Prisma, PostgreSQL, React, React Native, Expo, LiveKit, Claude API

## Convención de ramas

- `main` es producción, nunca se toca directamente.
- `develop` es la rama de integración donde se mergea todo.
- Cada feature va en una rama con el formato `feature/nombre-descriptivo`.
- Cuando una feature está lista se abre un pull request a `develop` y tiene que ser revisado por al menos una persona antes de mergear.
