# ═══════════════════════════════════════════════════════════════
# VetConnect — MOBILE — Requirements / Instalación
# ═══════════════════════════════════════════════════════════════
# Expo SDK 54 (React Native 0.81) + expo-router + NativeWind
#
# ▶ CÓMO INSTALAR TODO (desde /mobile):
#     npm install
#
# ⚠ IMPORTANTE: si usás el monorepo, corré `npm install` desde la
#   RAÍZ (C:\...\conectavet). Si instalás solo en /mobile y luego
#   instalás backend/web, podés romper dependencias. Regla:
#     → instalar SIEMPRE desde la raíz.
#
# ▶ REQUISITOS PREVIOS (una sola vez):
#   Node.js >= 20
#   Android Studio + SDK (para correr en emulador/físico)
#   App "Expo Go" en el celular (para probar rápido)
#   - Para celular físico por USB: adb instalado (start.ps1 lo detecta
#     en %LOCALAPPDATA%\Android\platform-tools\adb.exe)
#
# ▶ CONFIGURAR .env (mobile/.env):
#   EXPO_PUBLIC_API_URL=http://<IP-DE-TU-PC>:3001
#   EXPO_PUBLIC_WS_URL=ws://<IP-DE-TU-PC>:3001
#   (start.ps1 lo configura solo: con -ADB usa localhost, sin -ADB
#    detecta la IP automáticamente)
#
# ▶ LEVANTAR LA APP:
#     npm start        → ejecuta start.ps1 (recomendado)
#     npm run start:metro → expo start plano
#     npm run android  → abre en emulador Android
#
