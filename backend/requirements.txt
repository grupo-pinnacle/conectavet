# ▶ REQUISITO PREVIO (una sola vez):
#   Node.js >= 20  →  https://nodejs.org  (verificar: node -v)
#   PostgreSQL remoto (Supabase) ya configurado en backend/.env
#
# ▶ PREPARAR BASE DE DATOS:
#     npx prisma migrate deploy    (aplicar migraciones)
#     npx prisma generate          (regenerar Prisma Client si hizo falta)
#   Verificar conexión: npx prisma db pull (debe introspectar sin error)
